Time is measured in years and centered within benchmark, so the intercept is the frontier at each benchmark's own reference date. No standard errors: the response is the empirical Pareto frontier P_t(c) sampled at the nodes of the envelope's fixed cost-date grid, and grid nodes are not observations. N is the nodes at which the frontier is defined; they resample a few dozen staircase corners, so N measures resolution, not information. No quadratic-versus-linear test: there is no likelihood to test and no sampling distribution to appeal to. Pooled covers the primary benchmarks only (aime, chess, fm13, gpqa, mystery), mapping them onto the common scale of Epoch's ECI (Epoch Capabilities Index) 2PL, in which logit accuracy on benchmark b is alpha_b (C - D_b): each slope over alpha_b estimates the same capability-scale slope, and the pooled coefficient is their information-weighted (w = alpha^2) average, sum(alpha b) / sum(alpha^2), in ECI points per unit regressor. The discriminations (estimated_slope_scaled in data/edi_scores.csv, downloaded from https://epoch.ai/data/edi_scores.csv on 2026-08-20) are aime 0.223, chess 0.120, fm13 0.169, gpqa 0.120, mystery 0.168, so one logit is worth 4.5-8.4 ECI points and pooled slopes read several times larger than the logit-scale columns beside them. The pooled intercept averages capability net of difficulty at each benchmark's own reference date, so unlike the slopes it carries no clean interpretation, and pooled N sums the primary benchmark columns. For this model the alpha^2 weights borrow an information interpretation the fit cannot support -- there is no likelihood behind it -- so the pooled figures are mechanical averages. One scale caveat: gpqa accuracy is rescaled for its 0.25 guessing floor before the logit (prepare_data.R), a scale on which Epoch's alpha_gpqa was not necessarily estimated.
