Time is measured in years and centered within benchmark, so the intercept is the frontier at each benchmark's own reference date. cost drop, %/qtr is 100*(1 - exp(-b_time / b_ln cost / 4)): the percentage fall in the cost of a fixed accuracy level per quarter (time is in years, hence the 4). Linear specification only -- with the quadratic's ln cost x time term the cost slope moves with date, so no single rate describes the column. No standard errors: the envelope is the solution of a constrained optimisation with no likelihood behind it, so none are reported rather than invented. N is the runs it must clear. No quadratic-versus-linear test: there is no likelihood to test and no sampling distribution to appeal to.
