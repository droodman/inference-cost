Time is measured in years and centered within benchmark, so the intercept is the frontier at each benchmark's own reference date. Robust (sandwich) standard errors, as the SFA objective is a quasi-likelihood in the Papke-Wooldridge sense. Quadratic adds ln cost2, time2 and ln cost x time; the test is a likelihood ratio test of all three jointly. Pooled covers the primary benchmarks only (aime, chess, fm13, gpqa, mystery), mapping them onto the common scale of Epoch's ECI (Epoch Capabilities Index) 2PL, in which logit accuracy on benchmark b is alpha_b (C - D_b): each slope over alpha_b estimates the same capability-scale slope, and the pooled coefficient is their weighted average with w = alpha_b^2 x years of observed history -- information about the shared capability times the time base the slopes are estimated over -- i.e. sum(alpha T b) / sum(alpha^2 T), in ECI points per unit regressor. The discriminations (estimated_slope_scaled in data/edi_scores.csv, downloaded from https://epoch.ai/data/edi_scores.csv on 2026-08-20) are aime 0.223, chess 0.120, fm13 0.169, gpqa 0.120, mystery 0.168, so one logit is worth 4.5-8.4 ECI points and pooled slopes read several times larger than the logit-scale columns beside them. The pooled intercept averages capability net of difficulty at each benchmark's own reference date, so unlike the slopes it carries no clean interpretation, and pooled N sums the primary benchmark columns. log sigma_u, the log of a logit-scale spread, converts as log sigma_u - log alpha_b before averaging; its time slope is scale-free and pools directly. Fits are independent across benchmarks, so pooled standard errors sum the per-benchmark covariance pieces. One scale caveat: accuracy is rescaled from each benchmark's guessing floor -- 0.25 on gpqa, 0.001 on aime, 0.092 on mystery, 0 elsewhere -- to 1 before the logit (prepare_data.R), a scale on which Epoch's alpha_b were not necessarily estimated.
